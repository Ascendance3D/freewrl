# Getting help

This is a volunteer modernization fork of FreeWRL. There is no formal support, but these channels
can help.

| You have | Go to |
| --- | --- |
| A bug in this fork | [Open a bug report](https://github.com/Ascendance3D/freewrl/issues/new/choose). |
| A security vulnerability | Report it privately. Follow [SECURITY.md](SECURITY.md). Do not open a public issue. |
| A question about building or using this fork | [Discussions, Q&A](https://github.com/Ascendance3D/freewrl/discussions/categories/q-a). |
| A question about FreeWRL itself | The [original FreeWRL project](https://sourceforge.net/projects/freewrl/) on SourceForge. |

Before you ask, read the [README](README.md), [CONTRIBUTING.md](CONTRIBUTING.md) and, for macOS,
[MACOS-STATUS.md](MACOS-STATUS.md).
